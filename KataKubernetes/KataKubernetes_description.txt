KataKubernetes
==============

I have a REST API written in C#/NET that I want to deploy to Azure Kubernetes. 
The deployment should contain two pods with ingress on a load balancer. 
What is needed to support the load balancer? And how is the app deployed to Azure Kubernetes?

1) The API is very simple and delivers a "hello world" response.

$ dotnet new webapi --output KataKubernetes
cd KataKubernetes
$ dotnet add package Microsoft.AspNetCore.OpenApi
$ dotnet sln migrate
remove .sln file

$dotnet run
>> http://localhost:5102/api/v1/hello?name=Marcus

2) Docker container and Registry
https://bterkaly.medium.com/running-asp-net-applications-in-kubernetes-a-detailed-step-by-step-approach-96c98f273d1a

tools:
Azure CLI
Podman/Docker for local builds
    Podman is a local docker container. It has the same command line syntax but uses 'podman' instead of 'docker'.

[optional] pull base image (https://hub.docker.com/r/microsoft/dotnet-sdk)
$ podman pull mcr.microsoft.com/dotnet/sdk:10.0

build & tag image
$ cp .\deploy\Dockerfile .
$ podman build . -t marcellos/simpleapi
$ rm .\Dockerfile

push image (need to connect to a container registry)
$ podman push marcellos/simpleapi

run locally
$ podman run -d -p 5102:5102 --name simpleapi marcellos/simpleapi
..
$ podman container stop hash
$ podman container rm hash
$ podman image rm hash

3) Kubernetes Manifests
https://stackoverflow.com/questions/65803681/how-to-setup-a-k8s-dotnet-core-api-with-replicas-and-ingress-as-load-balancer-on
https://kubernetes.anjikeesari.com/kubernetes/2-deploy-api/#implementation-details

enable local registry for minikube
podman > Settings > Resources > Minikube create new
podman > Settings > Proxy NO_PROXY=localhost,127.0.0.1,10.96.0.0/12,192.168.59.0/24,192.168.49.0/24,192.168.39.0/24
(admin powershell)
$ minikube delete
$ minikube start --insecure-registry "10.0.0.0/24"
$ minikube addons enable registry
(Registry addon with podman driver uses port 34483 please use that instead of default port 5000)
(Using image docker.io/registry:3.0.0)
(Using image registry.k8s.io/minikube/kube-registry-proxy:v0.0.11)
$ kubectl get service --namespace kube-system

(
port forwarding in background 
$ kubectl port-forward --namespace kube-system service/registry 34483:80 &
$ podman push marcellos/simpleapi localhost:34483/marcellos/simpleapi --tls-verify=false
*oudtdated*

$ kubectl port-forward --namespace kube-system service/registry 5000:80 
    keep running
> http://localhost:5000/v2/_catalog
$ podman run --rm -it --network=host alpine ash -c "apk add socat && socat TCP-LISTEN:5000,reuseaddr,fork TCP:host.docker.internal:5000"
    keep running
$ podman tag localhost/marcellos/simpleapi localhost:5000/marcellos/simpleapi
$ podman push localhost:5000/marcellos/simpleapi
)

$ minikube image load localhost:34483/marcellos/simpleapi
$ minikube image list
(localhost:41555/marcellos/simpleapi:latest)

(in UI> Images> push to minikube cluster)

$ cp .\deploy\*.yaml .
$ kubectl apply -f .\deployment.yaml
    (deployment.apps/simpleapi-deployment created)
    >> verify pod status, image pulling
$ kubectl apply -f .\service.yaml
    (service/simpleapi-service created)
$ kubectl apply -f .\ingress.yaml
    (ingress.networking.k8s.io/simpleapi-ingress created)
$ rm *.yaml
